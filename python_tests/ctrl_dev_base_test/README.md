# Comparing `src_ctrl` and `src_dev` on CAPITOUL

The bench builds `src_dev` with `-DTEB_UPSTREAM_CONS_BUGS` and ordinary `src_ctrl`
(without `TEB_UPSTREAM_CONS`). Each configuration is generated by modifying the
shared dictionary from `tests/CAPITOUL/namelist/namelist.nml`; **the same resulting
file** is passed to both trees in `tebopts/tebparams` format. `tebopts` explicitly
sets `nvec=1`, `teb_lcbs_scheme=.FALSE.`, exchange algorithms and thermal-roughness
rules. `tebparams` contains shared dynamic-roughness defaults and the garden
ratio. Keys are grouped using the same rules as the block test and the TEB 4.0.0
comparison.

```powershell
python -B python_tests/ctrl_dev_base_test/compare.py --toolchain-dir C:\msys64\ucrt64\bin
```

By default, each case has a short run (100 rows) and full CAPITOUL run (17999
rows). `--smoke-only` runs only the short cases. A new external directory is
created by default under `TEB_WORK_ROOT/TEB-Ru/ctrl_dev_base_test/<timestamp>`
(Windows: `W:\Work_TEB`). `--out-dir` selects another external directory;
existing runs are preserved and a path inside the checkout is rejected. On
another machine, specify an external path explicitly. Builds are under
`<out-dir>/build/dev_bugs` and `<out-dir>/build/ctrl`; `--build-root` selects
another external build root. To reuse builds, supply
`--skip-build --build-root <existing root>` and a new `--out-dir`.
`report.md` and `report.json` store per-case results, dictionary and executable
hashes, counts of rows with rain and snow, counts of rows with road and roof
snow fractions, first differences and maximum errors. Logs and CSVs remain in
the bench directory. Forcing is copied into its `input/`; programs run from
external case directories with short relative arguments. The SHA of the shared
parameter file is checked after copying to each case. Precision/FPE flags are
preserved and bounds checks are enabled; ignored Make recipe errors also count
as failure.

Ordinary `src_ctrl` remains single-column. It reads the new format and legacy
`tebparam`, retaining its physical defaults and merged `TEB_output.csv`.
`nvec>1`, CBS and block dumps are explicitly rejected. In the new group, output
switches accept only compatible defaults (the three CSV switches `.TRUE.`,
`teb_lwrite_test_dump=.FALSE.`).

For Moscow January 2024 forcing from `TEB_Work`:

```powershell
python python_tests/ctrl_dev_base_test/compare.py `
  --forcing-nml W:\TEB_work\Moscow_winter\forcing_ERA5\namelist_forcing.nml `
  --replacement-wind W:\TEB_work\Moscow_winter_nosnow\forcing_ERA5\forcing_txt\Forc_WIND.txt `
  --irrigation-months 1 1 `
  --out-dir W:\Work_TEB\TEB-Ru\ctrl_dev_moscow_winter `
  --toolchain-dir C:\msys64\ucrt64\bin
```

The full run here has 744 steps (743 output rows). The original
`Moscow_winter/Forc_WIND.txt` is damaged: it has only 240 rows and incorrect
values from the first row. The wind file from `Moscow_winter_nosnow` has all
744 rows; the other files of these two datasets are byte-identical except for
snow. The bench copies `Moscow_winter/forcing_txt/` into the results directory,
replaces only wind there, and sets the generated dictionary's path to this copy.
`TEB_Work` data are unchanged; sources and hashes are recorded in the report.
`--forcing-dir` selects another source data directory if needed. The January
irrigation schedule in the command above artificially enables this mode to
exercise the branch; other parameters come from the shared CAPITOUL base
configuration. `shade` is not activated in the January forcing: indoor
temperature stays below the shading threshold. `src_ctrl` and `src_dev` are
compared in this case, but the overall activity check returns `fail` and exit
code 1. The report shows comparison and activity-check results separately.

For the extended period from 1 December 2023 to 1 May 2024, use the verified
`D:\TEB_work\Moscow_D5_2023-24` dataset (3649 hourly records):

```powershell
python python_tests/ctrl_dev_base_test/compare.py `
  --forcing-nml D:\TEB_work\Moscow_D5_2023-24\forcing_ERA5\namelist_forcing.nml `
  --irrigation-months 1 4 `
  --out-dir W:\Work_TEB\TEB-Ru\ctrl_dev_moscow_2023_24 `
  --toolchain-dir C:\msys64\ucrt64\bin
```

All 16 tree comparisons passed in this run (8 configurations × short and full
runs; 3648 full-output rows). Irrigation was artificially enabled from January
to April to exercise that branch. `shade` does not affect results during this
period either: maximum base-case `TI_BLD` is approximately 295.57 K, below the
297.16 K shading threshold. Thus the overall bench status is `fail` for activity
while the output comparison is `pass`.

The new dictionaries set `dt` in `tebopts` and use `teb_ctype_*` keys. The wind
scheme is the string `'DEF'` or `'WANG'`. The saved flat CAPITOUL template is
converted by the generator before scenarios are applied; physical values,
comparison criteria and exclusions are preserved.

## Cases

| Case | Changes to the base configuration |
| --- | --- |
| `base` | Garden and greenroof off; `teb_lshade=.FALSE.` |
| `garden` | Garden on, `fr_garden=0.11`, `PROXY_OLD` |
| `greenroof` | Greenroof on, `teb_frac_gr=0.3`, `PROXY_OLD` |
| `garden_greenroof` | Garden and greenroof enabled together |
| `irrigation` | Road irrigation enabled with the base dictionary's summer schedule |
| `wang_zd` | `teb_ctype_wind = 'WANG'`, `teb_ctype_zd_town='0.4H'` |
| `no_bem` | `teb_ctype_bem='DEF'`, `teb_frac_gz=0.0` |
| `shade` | `teb_lshade=.TRUE.` with BEM enabled |

`garden`, `greenroof` and their combination use the historical `PROXY_OLD`
scheme shared by both trees. Garden and greenroof are disabled in all other
cases. Glazing fraction must be zero with BEM disabled; otherwise both drivers
stop.

## Criterion

Time and the 12 shared forcing columns must match exactly. Numerical fields are
compared against a predefined list with tolerance
`abs(dev-ctrl) <= 1e-10 + 1e-10 * max(abs(dev), abs(ctrl))`.
Nonfinite values, a missing required column, an incorrect row count or mismatched
forcing cause failure. Differences in numeric text within tolerance are shown
in the report and do not by themselves violate the criterion.

`SOLAR_PROD` is written by `src_ctrl` but absent from `src_dev` when panels are
disabled. `WIND_TOP` has a different meaning with `teb_ctype_wind = 'DEF'`, so it
is excluded for these cases; it is compared in `wang_zd`. In `no_bem`, the test
compares `H_WASTE` and requires `HVAC_COOL`, `HVAC_HEAT` and `H_WASTE` in
`src_ctrl` to be zero. Only `src_ctrl` writes the two `HVAC_*` columns in this
mode.

The full run checks actual activity of added modes: nonzero garden and greenroof
fluxes, and a response relative to base `src_dev` for irrigation, Wang, BEM
disabling and shading. An inactive case is a failure.

The test compares shared outputs, not all internal states. In particular,
`PIMB_ROAD` from D10 is not included in the shared table and requires a separate
check.
